# Gift AI P0–P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通 PC + Mobile 的 Gift AI 调用通道（P0），并在礼尚往来 Dashboard/分析页提供「AI 解读」流式洞察（P1）。

**Architecture:** 复用现有 `alex_miaosha_ai` 的 `/ai/chat` 与 `/ai/chat/stream`。PC 从 `tools/ai-chat` 抽离可复用的 SSE/类型能力到 gift 侧 `GiftAiClient`；Mobile 新增 `baseService.ai` 与同契约客户端。P1 将 analysis overview（及可选 trend/ranking）放入 `context`，`bizType=gift-analysis`，按钮触发流式展示；AI 不写库。

**Tech Stack:** Vue 3 + TypeScript、Ant Design Vue（PC）、Vant（Mobile）、fetch SSE、Vitest、现有 gateway JWT `/api/am-ai`

**Spec:** `docs/superpowers/specs/2026-09-01-gift-ai-opportunity-roadmap-design.md`（P0–P1 only；P2–P4 / ASR backlog 另开计划）

## Global Constraints

- ID 在 AI `context` 中必须为 **string**，禁止 JS number
- API 响应一律 `const { code, data, message } = await ...`
- AI **永不**直接调用 gift CRUD；本阶段只展示文案
- 金额数值解读可引用 overview 数字，但不调用/覆盖 `recommend-amount`
- 敏感数据允许进模型（姓名/金额）；手机号默认不进 `context`
- 权限：无 `gift:view`（或页面已有查看权）不展示 AI 入口
- 未获用户 **Proceed** 前不得改业务代码（本文件仅为计划）
- 语音 ASR **不在本计划范围**（Backlog）
- PC：已由 unplugin 自动导入的 Vue API / AntD 组件禁止重复手动 import
- Mobile：改 `src` 后需 `npm run graphify:update`（若环境可用）

it('keeps *Id fields as string and omits phone-like keys', () => {

		overview: { totalReceive: 100, hostPersonId: '1234567890123456789', phone: '13800138000' },
