> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On user delete, invalidate org/role bindings, clear permission cache, and kick login sessions; add Org/Role list data permission via `DataPermission.Scope`.

**Architecture:** Extend `deleteTUser` into a transactional cleanup orchestrator reusing `OrgUserInfo`/`RoleUserInfo` status invalidation and existing logout Redis key shapes. Extend `@DataPermission` with `Scope.USER_IDS|ORG_ID` and branch in `DataPermissionHandlerImpl`; annotate `OrgInfoMapper.getPage` / `RoleInfoMapper.getPage` only.

**Tech Stack:** Spring Boot 2.7, MyBatis-Plus, JSqlParser data-permission interceptor, RedisUtils + LoginKey, JUnit 5 (`spring-boot-starter-test` already on `user_boot`).

```java
private Expression getOrgIdWhere(Expression where, TUserVo loginUser, DataPermission annotation) {
    if (loginUser == null || loginUser.getOrgInfoVo() == null || loginUser.getOrgInfoVo().getId() == null) {
        // no org → no rows
        EqualsTo impossible = new EqualsTo();
        impossible.setLeftExpression(new Column(new Table(annotation.table()), annotation.field()));
        impossible.setRightExpression(new LongValue(-1L));
        return where == null ? impossible : new AndExpression(where, impossible);
    }
    EqualsTo eq = new EqualsTo();
    eq.setLeftExpression(new Column(new Table(annotation.table()), annotation.field()));
    eq.setRightExpression(new LongValue(loginUser.getOrgInfoVo().getId()));
    return where == null ? eq : new AndExpression(where, eq);
}
```

Harden `getAdminWhere` subquery WHERE with AND status/is_delete if columns exist on `t_org_user_info` (they do: `status`, `is_delete`):

`UserDeleteCleanupServiceImpl`:

```java
@Transactional(rollbackFor = Exception.class) // only if called inside deleteTUser's transaction — prefer NO class-level; let deleteTUser own @Transactional
public void cleanupAfterUserDeleted(String userId) {
    // invalidate org
    List<OrgUserInfo> orgs = orgUserInfoService.list(Wrappers.<OrgUserInfo>lambdaQuery()
        .eq(OrgUserInfo::getUserId, userId)
        .eq(OrgUserInfo::getStatus, SysConf.VALID_STATUS));
    for (OrgUserInfo row : orgs) {
        row.setStatus(SysConf.INVALID_STATUS);
        orgUserInfoService.updateById(row);
    }
    // invalidate roles — same pattern on RoleUserInfo
    // redis permission_context
    try {
        redisUtils.delete(LoginKey.loginKey, "permission_context:" + userId);
    } catch (Exception e) { log.error(...); }
    // kick sessions
    // TUserLogin.userId is Long; org/role relation tables use String userId
    Long userIdLong = Long.valueOf(userId);
    List<TUserLogin> logins = tUserLoginService.list(Wrappers.<TUserLogin>lambdaQuery()
        .eq(TUserLogin::getUserId, userIdLong));
    for (TUserLogin login : logins) {
        try {
            if (StringUtils.isNotEmpty(login.getTokenId())) {
                String barToken = redisUtils.get(LoginKey.loginUuid, login.getTokenId());
                redisUtils.delete(LoginKey.loginUuid, login.getTokenId());
                if (StringUtils.isNotEmpty(barToken)) {
                    redisUtils.delete(LoginKey.loginToken, barToken);
                } else if (StringUtils.isNotEmpty(login.getToken())) {
                    redisUtils.delete(LoginKey.loginToken, login.getToken());
                }
            }
            // Optional: LoginKey.loginOnlineUser if present in codebase
            if (login.getTokenId() != null) {
                redisUtils.delete(LoginKey.loginOnlineUser, login.getTokenId());
            }
        } catch (Exception e) { log.error(...); }
    }
}
```

Verify `LoginKey.loginOnlineUser` exists before using — if absent, omit that delete.

`TUserServiceImpl.deleteTUser`:

```java
@Override
@Transactional(rollbackFor = Exception.class)
public Boolean deleteTUser(String ids) {
    if (StringUtils.isEmpty(ids)) {
        return true;
    }
    List<String> idArr = Arrays.stream(ids.split(","))
        .map(String::trim).filter(s -> !s.isEmpty()).collect(Collectors.toList());
    if (idArr.isEmpty()) {
        return true;
    }
    tUserMapper.deleteBatchIds(idArr);
    for (String userId : idArr) {
        userDeleteCleanupService.cleanupAfterUserDeleted(userId);
    }
    return true;
}
```
