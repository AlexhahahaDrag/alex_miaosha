# RBAC 批次 2：S2 一致性与缓存收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落实 `docs/testing/rbac-maturity-scorecard.md` 第 6 节批次 2 的 13 条 S2 登记册条目：补齐机构/角色/权限的唯一与结构校验、菜单/权限/关系读路径数据权限、删除级联失效关系行、`permission_context` 主动失效，以及 PC 菜单表单校验与移动端权限码并集。

**Architecture:** 后端延续批次 1 模式（`@DataPermission` + Service 归属守卫 + `SystemException` 含「无权」/业务拒绝对话）；缓存失效抽公共 helper，挂到 assign / 删角色权限 / 删权限点等变更点。PC 按 role/org 配置驱动补 `rulesRef`；mobile 将 `buildPermissionContext` 对齐 PC `normalizePermissionContext` 的权限码并集形状。测试以 JUnit+Mockito（BE）与 vitest（PC/MB）为主；midscene 仅作 PC 可选手工验收。

**Tech Stack:** JDK 17 + JUnit 5 + Mockito；MyBatis-Plus；Redis `LoginKey.loginKey`；Vue3 + Ant Design Vue（PC）；Vant + vitest（mobile）。
